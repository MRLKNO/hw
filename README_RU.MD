# hw

[English](README.md) | [Русский](README_RU.md)

Маленькая CLI-утилита, которая создаёт "Hello, world!" проекты для разных языков программирования. Удобно, когда нужно быстро проверить, что тулчейн работает, а писать всё с нуля лень.

Проекты создаются правильно: `cargo new` для Rust, `dotnet new` для C#, `go mod init` для Go и так далее. По желанию утилита сразу собирает и запускает результат.

## Использование

```
hw <язык> [имя] [флаги]
```

| Флаг            | Описание                    |
|-----------------|-----------------------------|
| `-b`, `--build` | создать и собрать           |
| `-r`, `--run`   | создать, собрать и запустить |
| `-l`, `--list`  | список поддерживаемых языков |
| `-h`, `--help`  | справка                     |

`имя` — название папки проекта. По умолчанию `hello-<язык>`.

### Примеры

```
hw rust            # просто создать проект
hw cpp test -r     # создать ./test, собрать и запустить
hw zig --build     # создать ./hello-zig и собрать
hw -l              # список языков
```

## Поддерживаемые языки

| Язык       | Алиасы               | Нужно             |

| rust       | `rs`                 | `cargo`           |
| c          |                      | `gcc`             |
| cpp        | `c++`, `cc`          | `g++`             |
| zig        |                      | `zig`             |
| go         | `golang`             | `go`              |

| nim        |                      | `nim`             |

Тулчейн нужен только для тех языков, которыми вы реально пользуетесь.

## Установка

Из исходников:

```
git clone <repo-url>
cd hw/rust/
cargo install --path .
```

Как `.deb` пакет (Debian/Ubuntu):

```
cargo install cargo-deb
cargo deb
sudo dpkg -i target/debian/hw_*.deb
```

## Добавление языка

Каждый язык — это одна запись в массиве `LANGS` в `src/main.rs`: файлы для записи, опциональные команды scaffold/setup и команды сборки/запуска. `{name}` в команде заменяется на имя проекта.

## Ограничения

- Пока только Unix-подобные системы: собранные бинарники запускаются как `./name`.
